# Data directory

The project separates source material from analysis-ready data.

## `raw/`
Files retained in source-oriented form. These should not be manually edited during analysis.

- `state_income_tax_source.xlsx` — historical state income-tax workbook used by the project's cleaning pipeline.
- `federal_tax_brackets_2024_2025.csv` and `.pdf` — supporting federal tax-bracket source files retained from the original project package.

## `processed/`
Files produced after cleaning or normalization and used by the analytical pipeline.

- `cleaned_state_income_tax_rates.xlsx` — cleaned multi-sheet state-tax workbook.
- `state_income_tax_master.csv` — normalized state/year/filing-status bracket table used by `TaxEngine`.
- `state_purchasing_power_married_joint.csv` — generated when `analysis.ipynb` runs successfully.
- `state_purchasing_power_single.csv` — generated when `analysis.ipynb` runs successfully.

The final two CSV files are intentionally generated by the notebook because they depend on current FRED data and live tax-source collection.
